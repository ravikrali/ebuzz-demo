How AI agents build & ship eBuzz

A fleet of 31 specialised build agents writes, tests, secures and deploys the platform. A small human team supervises and approves every gate that matters: architecture, security, money, legal and production releases. It takes 26 weeks from kickoff to public launch in the wedge vertical.

How agents build & deploy, end to end

Every change moves through the same governed pipeline. Agents do the work, and people approve the steps that carry risk.

Plan
The Orchestrator turns the PRD into tickets with acceptance criteria and dependencies.
Build in a sandbox
The engineer agent works in an isolated container with synthetic data and scoped, short-lived credentials.
Test
Unit, contract, e2e, accessibility and eval suites are written alongside the code.
Pull request
Nothing merges without a PR: SAST, SCA, secret and IaC scans run automatically.
Review
The Code Review agent reviews every PR. A human also approves protected paths (money, auth, crypto, RBAC).
Signed build
Container images are signed, with SBOM and SLSA provenance.
Staging
Evals, DAST, load tests and a preview for human UX sign-off.
Canary deploy
The Release agent rolls out 5% → 25% → 100% via Argo CD and flags, with auto-rollback on SLO breach.
Operate
The SRE agent watches SLOs and cost. Incidents get a human commander.
🔐 Guardrails for build agents
  • No production data or credentials, ever
  • One scoped GitHub token per agent; no direct pushes to main
  • Network egress allow-list (package registries, vendor sandboxes)
  • Token and time budgets per ticket; the Orchestrator kills runaway loops
  • Full transcript and tool-call audit trail in Langfuse
👩‍💻 Human-in-the-loop gates
  • Architecture & threat models (CTO, Security Lead)
  • Protected-path PRs: two-person rule
  • Legal documents (outside counsel)
  • Every production release touching money or auth
  • Go/no-go at week 22 and launch
📏 Definition of done
  • Acceptance criteria pass in e2e tests
  • No new critical/high security findings
  • Accessibility checks pass
  • Docs & runbooks updated
  • Agent evals ≥ threshold (for AI features)
