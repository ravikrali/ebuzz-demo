How eBuzz.ai is built

A local-first, agent-native marketplace on AWS. It has chat-first clients, a real-time Deal Room, an event-driven core, and a governed AI agent platform. Security and compliance are designed in from the start: personal data stays encrypted on users' devices, and people approve anything that moves money, publishes content or signs contracts.

Architecture principles

Six decisions shape everything else.

1

Chat-first, component-rich

The chat stream carries typed UI components (cards, tables, forms). Dashboards hold the full lists.

2

Local-first data

SQLite on every device syncs with Postgres. PII lives in an end-to-end encrypted vault.

3

Event-driven core

Orders, offers, games and agents publish events. Durable workflows handle money.

4

Governed agents

Agents reach services only through MCP tools with least privilege, budgets, evals and human gates.

5

Protocol-ready

UCP/ACP endpoints let external AI agents shop eBuzz live offers.

6

Buy, don't build (non-core)

We build Deal Room, Concierge, games and the ledger. Payments, tax, shipping and identity are bought.

Logical architecture

Layers from the device to external services. Security & compliance and observability run through every layer.

Domain services

Each service owns its Postgres schema and publishes events. There is no cross-service database access. The Ledger (wallet credits, commissions, payouts) is append-only, with double-entry bookkeeping.

Agent platform

The orchestrator (Temporal) runs agent workflows. The runtime calls Claude through the model gateway. Tools are MCP servers backed by domain APIs. Side effects above set limits go to the approval queue.

Sync & privacy

The sync service replicates allowed rows to each device. Vault columns hold only ciphertext. Fulfilment tokens release a shipping address to one vendor for one order.

Key flow: "Ask for a better deal"

The shopper keeps chatting while vendors respond over several minutes.

Deployment & environments

Everything is deployed through GitOps. Every environment is created from the same Terraform modules.

Governance

Fractional CISO from month 0, and a Security Lead hired by month 4. A Risk & Compliance committee meets monthly. An AI governance board approves agent autonomy changes.

Testing cadence

Scans run on every PR, DAST weekly, a third-party pentest before launch and yearly, AI red-teaming quarterly, and a public bug bounty 3 months after launch.

Budget (Year 1)

About $420k: people ($260k), tooling ($90k), pentest and audits ($70k). That's roughly 8% of the seed round, sized for a trust-sensitive marketplace.
